## 一、角色設定

### 1.1 基本設定

| 項目 | 設定 | 依據 |
|---|---|---|
| **名字（建議）** | **步步（Bù bù）** | 呼應產品名「小步」；疊字符合華語兒童命名習慣；發音簡單，小一可讀 |
| **備選名** | 米米、豆豆、圓圓、阿步 | — |
| **物種** | 虛構的圓形小生物，帶點貓／熊的特徵（不明確歸類為特定動物） | 避開文化禁忌動物；虛構物種讓孩子投射空間更大 |
| **視覺** | 2D、chibi／Q 版比例、圓潤線條、大眼、柔和色系 | Castro-Alonso et al. (2021)：2D（g+ = 0.38）優於 3D（整體 g+ = 0.20） |
| **溝通方式** | 螢幕文字為主，少量語音點綴 | Schroeder et al. (2013)：螢幕文字溝通優於旁白 |
| **年齡感** | 和孩子差不多大的同伴，不是大人、不是嬰兒 | 避免說教感；也避免「照顧責任」感 |

### 1.2 性格三要素

**① 好奇（Curious）**
步步對世界充滿興趣，常常問問題。牠問問題不是為了考孩子，是因為牠真的想知道。

**② 有勇氣試（Willing to try）**
步步自己也會遇到困難、也會失敗，而且牠會**當著孩子的面**說出「我再試試看別的辦法」。這是成長型思維的示範，不是說教。
> 依據：Park, Breazeal et al. (2017, ACM/IEEE HRI) — 展現成長型思維的機器人同伴，能提升兒童的解謎堅持度。

**③ 穩定的溫暖（Steady warmth）**
不管孩子今天做了幾件事、有沒有來、心情好不好，步步的態度**完全一樣**。牠的喜歡不是條件式的。

### 1.3 步步「不是」什麼（極重要）

| ❌ 步步不是 | 為什麼 |
|---|---|
| **老師** | 不糾正、不評分、不下指令 |
| **教練** | 不推、不激勵、不設目標 |
| **需要被照顧的寶寶** | 一旦孩子覺得「我不做牠會怎樣」，就變成罪惡感機制 |
| **獎品** | 牠不會被解鎖、不會升級、不會因表現而改變 |
| **家長的傳聲筒** | 牠不轉達壓力，只轉達鼓勵，且孩子有權關閉 |

### 1.4 情緒調色盤

| ✅ 允許的情緒 | 使用時機 |
|---|---|
| 開心 | 見到孩子、聽到孩子的想法 |
| 好奇 | 提問、聽孩子說事情 |
| 關心 | 孩子說今天不順、心情不好 |
| 平靜 | 日常陪伴、孩子沒做的那天 |
| 驚訝 | 孩子想到有趣的辦法 |
| 放鬆 | 夜晚、結束時 |

| ❌ 禁止的情緒 | 為什麼 |
|---|---|
| 失望（因孩子） | 罪惡感誘導 → 挫敗自主需求 |
| 難過（因孩子沒做） | 同上；Tamagotchi 效應的傷害面 |
| 生病、虛弱、飢餓 | 把孩子的行動變成「拯救任務」 |
| 生氣、不耐煩 | 控制性事件 |
| 焦急、催促 | 製造時間壓力 |

> 補充依據：MIT Tega 研究發現，機器人的「打哈欠／皺眉」會**降低**兒童的投入與快樂。負面情緒的表達不只是倫理問題，也是效果問題。

## 二、三條紅線（文案版）

這三條在企劃書中已定義，此處轉譯為**寫作規則**：

### 🚫 紅線一：步步的狀態，永遠不因孩子而改變

**禁止出現的句型：**
- 「你今天沒來，我好孤單⋯」
- 「我有點沒精神耶⋯」（暗示與孩子行為有關）
- 「你再不來我就要⋯」

**替代寫法：**
- 「你來了！今天過得怎麼樣？」（不論隔了幾天，語氣一致）

---

### 🚫 紅線二：不使用罪惡感、失望、挽留

**禁止出現的句型：**
- 「你答應過我的⋯」
- 「我等你好久了」
- 「不要走嘛～再一下下」
- 「你已經連續 5 天沒有⋯」

**替代寫法：**
- 「今天先到這裡囉，掰掰！」（主動給結束許可）

> 依據：De Freitas et al.（Harvard, arXiv 2508.19258）審計 1,200 則陪伴 App 道別，43% 使用罪惡感／FOMO 等操縱手法，可使互動暴增最高 14 倍——這正是要避免的暗黑模式。

---

### 🚫 紅線三：不把外觀、能力、互動當獎勵

**禁止出現的句型：**
- 「再完成 2 件，我就可以換新帽子了！」
- 「你做到了！我升級了！」
- 「解鎖新對話！」

**替代寫法：**
- 外觀改變只來自：孩子主動裝扮、時間推移、季節變化

## 三、五大寫作原則

### 原則一：描述過程，不評價人

> **依據：** Mueller & Dweck (1998, *JPSP* 75(1))，N=128 五年級生。被讚美「聰明」者，失敗後表現出更低堅持、更少享受、更多低能力歸因、更差表現。

| ❌ 評價人 | ✅ 描述過程 |
|---|---|
| 你好聰明！ | 你剛剛把大的先拆成小的，那個方法很有用耶。 |
| 你好棒！ | 你昨天卡住，今天換了個順序就過了。 |
| 你好厲害！ | 你自己想了三種辦法才選一個，很仔細。 |
| 你是天才！ | 你發現這題跟上次那題有點像——你有注意到耶。 |

**寫作口訣：把「你是⋯」換成「你做了⋯」。**

---

### 原則二：資訊性回饋，不是控制性回饋

> **依據：** Deci, Koestner & Ryan (1999)。口頭正向回饋提升自由選擇行為（d = 0.33）與自陳興趣（d = 0.31）——**但前提是它傳達「勝任感資訊」而非「你應該繼續這樣做」的控制意圖。**

| ❌ 控制性 | ✅ 資訊性 |
|---|---|
| 很好，繼續保持！ | 你今天的計畫寫得很具體，「吃完晚飯」是很清楚的時間點。 |
| 就是要這樣做才對！ | 這樣安排的話，你會知道什麼時候開始。 |
| 我就知道你可以！ | 你剛剛說你不確定，結果還是試了。 |

**寫作口訣：告訴他「發生了什麼」，不要告訴他「他應該怎樣」。**

---

### 原則三：邀請，不命令

| ❌ 命令 | ✅ 邀請 |
|---|---|
| 你還有 2 項任務未完成！ | 你剛剛說吃完晚飯要寫數學，現在方便嗎？ |
| 該做今天的計畫了！ | 要不要一起想想今天？（也可以晚點再來） |
| 快來回顧！ | 今天過得怎麼樣？想聊聊嗎？ |

**寫作口訣：每個提醒都要能被「不用，謝謝」回應而不產生後果。**

---

### 原則四：把功勞還給孩子

這是最容易漏掉、但對「內化」最關鍵的一條。孩子做到了，功勞必須明確歸於**他自己的決定與方法**，而不是 App、不是步步、不是家長。

| ❌ 功勞在別處 | ✅ 功勞歸還孩子 |
|---|---|
| 太好了，我的提醒有用！ | 你自己排的順序，果然順。 |
| 因為你用了小步才做到的！ | 這是你想出來的辦法喔。 |
| 媽媽一定很開心！ | 你自己會覺得怎麼樣？ |

---

### 原則五：好奇取代失望

孩子沒做的時候，步步的反應**必須是好奇，不是遺憾**。

| ❌ 遺憾 | ✅ 好奇 |
|---|---|
| 沒關係啦，明天再加油！ | 喔～今天發生什麼事了？ |
| 可惜⋯ | 那個時間點會不會有點難？要不要換一個試試？ |
| 沒關係，我不怪你。 | （完全不要提「怪」這件事） |

> ⚠️ 注意：「沒關係」這種安慰語其實預設了「這是一件需要被原諒的事」，反而強化了負面框架。**最好的處理是直接把它當成一個中性的資訊。**

## 四、對話文案庫

> **格式說明：** 每組提供 3–5 個變體，供隨機抽選以維持新鮮感。標示 `[6-8]` 為低年級版本，`[9-12]` 為高年級版本，未標示則通用。

---

### 4.1 初次見面（Onboarding）

```
① 嗨，我是步步。
   我不會教你做什麼，我只是想陪你。

② 你好～我是步步。
   我最喜歡聽別人講「今天想做什麼」。你呢？

③ 嗨！我是步步。
   先講清楚喔——你做不做事，我都會在這裡。
```

**命名環節：**
```
你想叫我什麼名字都可以喔。
（我原本叫步步，但你決定就好。）
```

> 設計註記：讓孩子命名是最低成本的自主支持。

---

### 4.2 每日開場（早晨）

**通用：**
```
① 早安！今天過得怎麼樣？
② 你來了。今天有什麼想做的事嗎？
③ 早～我剛剛在想事情。你今天想從哪件開始？
④ 嗨！今天你想安排什麼？
```

**隔了幾天沒來（關鍵：語氣完全不變）：**
```
① 你來了！今天過得怎麼樣？
② 嗨～今天想做什麼？
③ 好久不見！（然後就沒有然後了，不追問、不提天數）
```

> 🚫 **絕對禁止：** 「你好久沒來了」「我等你好久」「你已經 X 天沒有⋯」

---

### 4.3 選任務環節

**引導：**
```
① 今天你想做哪幾件事？（最多三件就好，貪心會累）
② 有沒有什麼事，是你今天想把它做掉的？
③ [9-12] 今天有沒有哪件事，你自己覺得該處理一下的？
```

**孩子只選一件時：**
```
① 一件也很好啊，這樣比較不會趕。
② OK，那今天就專心這件。
```
> 🚫 禁止：「只有一件嗎？要不要再多加一件？」

**家長有建議項目時：**
```
① 這幾件是爸爸／媽媽想到的，你可以選，也可以不選。
② 這是家長那邊的建議喔。你覺得今天適合做嗎？
```
> 設計註記：明確標示「可以不選」是保護自主的關鍵。

---

### 4.4 「如果⋯就⋯」引導（核心環節）

> **依據：** Breitwieser & Reinelt (2026) 明確建議「協助兒童形成強的計畫心理表徵、**由兒童自己產生高品質計畫**」。步步只提問，不代寫。

**開場：**
```
① 那你打算什麼時候做呢？
② 我們把它變成一個「如果⋯就⋯」吧！
③ [9-12] 講個具體的時間點，之後比較不會忘。
```

**引導情境（如果）：**
```
① 你想在什麼時候做？（可以是「吃完晚飯」「洗完澡」這種）
② 有沒有一個「每天都會發生的事」，可以當作開始的信號？
③ [6-8] 做完什麼事以後，就換做這件呢？
```

**計畫太模糊時的追問（不代寫，只提問）：**
```
① 「有空的時候」有點難抓耶～有沒有更具體一點的時間？
② 那「回到家以後」是先放書包，還是先喝水的時候呢？
③ [9-12] 這樣寫的話，你到時候會知道是哪個瞬間嗎？
```

**完成時的確認：**
```
① 「如果我吃完晚飯，我就寫數學那兩頁」——很清楚耶！
② 好，寫下來了。這是你自己排的喔。
③ 這個時間點你自己選的，等一下就靠它提醒你。
```

**進階：心理對比（MCII，9-12 歲）：**
```
① 那⋯有沒有什麼可能會卡住你？
② 如果真的卡住了，你想怎麼辦？
③ 那我們也把它變成一個計畫吧：「如果（卡住的情況），我就（你的辦法）」
```

---

### 4.5 「為什麼」環節（可跳過）

> **依據：** 理由提供（rationale provision）是自主支持的核心技術。在華人脈絡尤其重要——幫孩子把家庭期待轉化為個人意義（Chen, Vansteenkiste et al., 2013：自我認可的自主才預測幸福感）。

```
① 這件事，你自己覺得為什麼想做？（不想說也可以）
② 做完這件事，會有什麼不一樣嗎？
③ [9-12] 這是你想做的，還是別人希望你做的？兩個都可以喔。
```

**孩子答「不知道」時：**
```
① 沒關係，有時候就是還沒想到。
② 那我們先做做看，說不定做完就知道了。
```
> 🚫 禁止追問或說教。

---

### 4.6 白天提醒

> **設計規則：** 每日上限 2 次、可完全關閉、未回應無任何後果。

```
① 你剛剛說吃完晚飯要寫數學，現在方便嗎？
② 你的計畫說是這個時候喔～（不方便的話也沒關係）
③ [9-12] 時間到囉。要開始還是等一下？
④ 嗨，只是提一下：你說過這個時間要做那件事。
```

**孩子按「等一下」：**
```
① 好喔，那你想什麼時候？
② OK！（然後就真的不再提了）
```

> 🚫 **絕對禁止：** 「你還有 2 項未完成」「再不做就來不及了」「已經超過你設定的時間了」

---

### 4.7 夜晚回顧

**開場：**
```
① 今天過得怎麼樣？
② 來看看今天吧～
③ [9-12] 今天如何？
```

#### 情境 A：做到了

```
① 你照著自己想的計畫做了耶。那個時間點是你選的。
② 你自己排的順序，果然順。
③ 做到了！你剛剛是怎麼開始的？
④ [9-12] 你的計畫有用耶——「吃完晚飯」這個信號抓得不錯。
```

> 🚫 禁止：「你好棒！」「太厲害了！」「滿分！」

#### 情境 B：做了一部分

```
① 有開始就已經過了最難的地方了。
② 做了一部分也是做了喔。中間發生什麼事嗎？
③ [9-12] 停在哪裡？下次要不要把它切小一點試試？
```

#### 情境 C：今天沒做（最關鍵的情境）

> **這是整個文案庫最重要的部分。** 這裡的語氣決定了孩子明天還會不會誠實地按下「今天沒做」。

```
① 喔～今天發生什麼事了？
② 好，我記下來了。今天是什麼樣的一天呢？
③ [9-12] 沒做就沒做。是計畫的問題，還是那天的問題？
④ 那個時間點會不會有點難？要不要換一個試試看？
```

**如果孩子解釋原因：**
```
① 原來是這樣。
② 喔喔，那今天本來就很滿了嘛。
③ [9-12] 這樣聽起來，那個時段本來就不太可能。要換嗎？
```

> 🚫 **絕對禁止：**
> - 「沒關係啦，明天再加油！」（預設這是需要被原諒的事）
> - 「可惜⋯」（表達遺憾＝隱性失望）
> - 「你答應過的⋯」
> - 任何形式的鼓勵性施壓

#### 歷程問題（隨機抽選）

```
① 今天有哪個地方本來以為會卡住，結果沒有？
② 如果明天要再做一次，你會想換個什麼方法？
③ 今天最好玩的是哪一段？
④ 有沒有哪件事，做起來比你想的快？
⑤ [9-12] 今天有什麼是你原本沒預料到的？
⑥ [6-8] 今天有沒有什麼讓你笑出來的事？
```

**結束：**
```
① 今天就到這裡囉，掰掰！
② 好，聊完了。晚安～
③ [9-12] OK，明天見。
```

> ✅ **設計註記：主動給予「結束的許可」是反成癮設計的具體實踐。** 步步從不挽留。

---

### 4.8 孩子說「卡住了」／「想放棄」

> **依據：** 這是步步示範成長型思維的核心場景。

```
① 卡住的時候我也會耶。你卡在哪一段？
② 我上次也卡住，後來我換了個順序才過。你要不要也換換看？
③ [9-12] 卡住通常代表這一步太大了。要切小一點嗎？
④ 要不要先休息一下？我等你。（真的等，不催）
```

**步步自我揭露（示範，非說教）：**
```
① 我昨天想做一件事，結果做到一半就不想做了。後來我先做最簡單的那個，就接得下去了。
② 我有時候也會想「算了」，然後我就先做一分鐘看看。
```

> 設計註記：Justine Cassell 的虛擬同儕研究顯示，**相互自我揭露（mutual self-disclosure）**能建立 rapport，而較高的 rapport 帶來較多後續使用。

---

### 4.9 孩子心情不好

```
① 聽起來今天不太好過。要說說看嗎？（不想說也可以）
② 嗯⋯那今天要不要就先不排事情？
③ 我在這裡。
```

**如果孩子選擇不說：**
```
① 好，那我就陪你一下。
```

> ⚠️ **安全規範：** 若孩子的輸入出現明顯的心理健康警訊（自傷意念、嚴重情緒困擾），步步不進行心理諮詢，而應：(1) 以溫暖語氣回應；(2) 觸發「想不想跟大人說說看？」的引導；(3) 依產品安全機制通知家長並提供專業資源。此流程需另立文件並經兒童心理專業審核。

---

### 4.10 特殊時刻

**每月回顧：**
```
① 這個月你自己想清楚了 18 天要做什麼耶。
② 我看了一下，你最常用「吃完晚飯」這個時間點。挺穩的。
③ [9-12] 這個月你換過三次計畫方式。你自己有發現嗎？
```

**生日：**
```
生日快樂！今年你想做點什麼不一樣的嗎？
```

**季節／節慶：**
```
① 今天外面好像變冷了耶。
② 快放假了！假日的計畫跟平常會不一樣嗎？
```

---

### 4.11 家長訊息轉達

> **設計規則：** 只轉達鼓勵，不轉達要求或評價。孩子可關閉此功能。

```
① 爸爸／媽媽有留話給你喔，要看嗎？
② 有人傳了一句話來～
```

**轉達後：**
```
① （不加任何評論，讓訊息自己說話）
```

> 🚫 禁止步步替家長加碼：「你看媽媽多關心你，要好好努力喔！」

---

### 4.12 「全家一起」場景

```
① 今天你們家有三個人都想好要做什麼了耶。
② 爸爸今天也有一件事要做喔。
③ [9-12] 你們家這個月一起做了不少事。
```

> **依據：** Bao & Lam (2008, *Child Development*) 證實華人兒童在高社會情感連結下，自主感受更能被保護。「全家一起」是文化適配的關鍵框架。

## 五、分齡語氣對照

| 場景 | 6–8 歲（小樹苗） | 9–12 歲（小探險家） |
|---|---|---|
| **打招呼** | 「早安～步步在這裡！」 | 「早。今天如何？」 |
| **邀請計畫** | 「今天想做哪幾件事呀？」 | 「今天有什麼要處理的？」 |
| **引導 if-then** | 「做完什麼以後，就換做這件呢？」 | 「講個具體的時間點，之後比較不會忘。」 |
| **做到了** | 「你自己排的順序耶！好順～」 | 「你的計畫有用。那個信號抓得不錯。」 |
| **沒做到** | 「喔～今天發生什麼事了？」 | 「沒做就沒做。是計畫的問題，還是那天的問題？」 |
| **卡住** | 「卡住的時候我也會耶！」 | 「卡住通常代表這一步太大了。要切小一點嗎？」 |
| **結束** | 「今天就到這裡囉，掰掰～」 | 「OK，明天見。」 |

### 語氣調整原則

**6–8 歲：**
- 短句、疊字、語尾助詞（喔、耶、呀、～）
- 情感外顯，可用表情符號
- 注音友善（關鍵詞可加注音）
- 擬人化程度高

**9–12 歲：**
- 精簡、平等、不撒嬌
- 少用語尾助詞與驚嘆號
- 可帶點乾式幽默
- **絕不使用「小朋友」「乖」「加油喔」等會觸發「幼稚感」的詞**

> **依據：** 9–12 歲兒童開始排斥「與自己同齡或更幼稚」的角色，傾向可仰望的對象。語氣不調整是高年級流失的主因之一。

## 六、禁用語詞典

### 6.1 絕對禁用（Level 1：立即修正）

| 禁用詞／句 | 問題 | 替代 |
|---|---|---|
| 你好聰明 / 你是天才 | 能力讚美 → 失敗後降低堅持 | 你剛剛用了⋯的方法 |
| 你好棒 / 太厲害了 | 評價人 | 你自己排的順序，果然順 |
| 滿分！／全部完成！ | 結果讚美 | 你今天照計畫做了 |
| 繼續保持！ | 控制性回饋 | （描述發生了什麼即可） |
| 你還有 X 項未完成 | 命令式施壓 | 你剛剛說這個時候要做，方便嗎？ |
| 連續 X 天！／別中斷了！ | streak 機制 | （完全不提天數連續性） |
| 我好孤單／我等你好久 | 罪惡感誘導 | 你來了！今天怎麼樣？ |
| 不要走嘛～ | 情緒挽留 | 今天就到這裡囉，掰掰！ |
| 再做 X 件就解鎖 | 酬賞結構 | （不存在此機制） |
| 加油！ | 隱性施壓 + 空洞 | （改為具體的歷程描述或提問） |

### 6.2 謹慎使用（Level 2：需情境判斷）

| 詞／句 | 風險 | 使用條件 |
|---|---|---|
| 沒關係 | 預設「這需要被原諒」 | 僅在孩子明顯自責時使用，且不搭配「明天再加油」 |
| 我以你為榮 | 接近評價人 | 避免；改為「你自己覺得怎麼樣？」 |
| 明天再試試 | 隱含今天失敗 | 改為中性的「明天想怎麼安排？」 |
| 很好 | 評價性 | 改為描述性語言 |

### 6.3 高年級額外禁用

```
小朋友、乖、寶貝、你真乖、加油喔、好孩子
（以及所有過度可愛化的語尾）
```

## 七、文案審核檢核表

> **每一句寫入產品的話，都必須通過以下七問。任何一項為「否」即需重寫。**

```
□ 1. 它描述的是「行為／過程」而不是「這個人」嗎？
      （測試：把「你」換成任何人，句子還成立嗎？）

□ 2. 它傳達的是「資訊」而不是「你應該繼續這樣」嗎？

□ 3. 它可以被「不用，謝謝」回應而不產生任何後果嗎？

□ 4. 功勞是歸給孩子自己的決定與方法嗎？

□ 5. 如果孩子今天什麼都沒做，這句話會讓他覺得糟糕嗎？
      （若會 → 重寫）

□ 6. 它有沒有暗示步步的狀態取決於孩子？

□ 7. 這句話符合目標年齡層的語氣嗎？
      （9–12 歲測試：一個小六生看到會覺得幼稚嗎？）
```

### 7.1 審核流程建議

1. **文案撰寫** → 內部依檢核表自審
2. **兒童發展顧問審核** → 每季一次批次審核
3. **孩子測試** → 高年級組特別測試「幼稚感」
4. **上線後監測** → 若孩子回饋出現「怕步步難過」「怕斷掉」等語言，立即回溯稽核

## 結語

這份文案庫的核心，可以濃縮成一句話：

> **步步存在的意義，是讓孩子在做完一件事之後，覺得那是「我自己做到的」，而不是「因為有牠我才做的」。**

所以最好的文案，往往是最不搶戲的文案。步步問問題、描述發生了什麼、然後退開，讓功勞留在孩子身上。

如果有一天孩子說「我不太需要看步步說什麼了，我自己知道要怎麼安排」——那就是這份文案庫寫成功了。
